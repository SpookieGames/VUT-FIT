# 📚 VUT FIT – Školské projekty

Repozitár obsahuje projekty a úlohy z predmetov prvého ročníka bakalárskeho štúdia na **VUT FIT v Brne**.

---

## 📂 Štruktúra

| Priečinok | Predmet                                | Popis                                  |
| --------- | -------------------------------------- | -------------------------------------- |
| `IZP`     | Základy programování                   | Projekty v jazyku C                    |
| `IOS`     | Operační systémy                       | Shell skripty, synchronizácia procesov |
| `IEL`     | Elektronika pro informační technologie | Výpočty obvodov, LaTeX dokumenty       |
| `INC`     | Návrh číslicových systémů              | UART RX controller, FSM v VHDL         |
| `ISC`     | Počítačový seminář                     | –                                      |
| `ISU`     | Programování na strojové úrovni        | –                                      |
| `IVH`     | Seminář VHDL                           | –                                      |
| `IVS`     | Praktické aspekty vývoje software      | Tímový projekt, testovanie             |
| `IZLO`    | Základy logiky pro informatiky         | –                                      |
