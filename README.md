# VUT FIT – školské projekty

Repozitár obsahuje projekty a cvičenia z bakalárskeho štúdia na Fakulte informačných technológií VUT v Brne.

## Štruktúra

Každý priečinok zodpovedá jednému predmetu.

| Priečinok | Predmet                                | Obsah                                       |
| --------- | -------------------------------------- | ------------------------------------------- |
| `ISC`     | Počítačový seminář                     | Úvodný predmet pred IZP                     |
| `IZP`     | Základy programování                   | Projekty v jazyku C                         |
| `IEL`     | Elektronika pro informační technologie | Výpočty obvodov, dokumenty v LaTeX          |
| `IZLO`    | Základy logiky pro informatiky         | Úlohy zamerané na SAT a SMT                 |
| `ISU`     | Programování na strojové úrovni        | Cvičenia ISU4–ISU12 v asembleri, testy      |
| `IOS`     | Operační systémy                       | Shell skripty, synchronizácia procesov      |
| `INC`     | Návrh číslicových systémů              | Prijímač UART (RX) ako FSM vo VHDL          |
| `IVH`     | Seminář VHDL                           | BCD čítač 8×8 na doske PYNQ-Z2              |
| `IVS`     | Praktické aspekty vývoje software      | Tímový projekt, testovanie                  |

## Použité technológie

C, Python, Bash, VHDL, LaTeX
